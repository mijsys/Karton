Wayland desktop environment

Karton brings the compositor, shell and session into one focused desktop.

Built on the Tektura compositor and expanded with Karton shell panels plus session services, the project aims for a fast, calm and configurable desktop for daily work.

Components

Three layers, one environment

Tektura compositor

A wlroots-based stacking compositor that stays lean, stable and themeable while keeping the desktop foundation predictable.

Karton shell

Top and side panels built as shell-layer clients, styled with a lightweight CSS-like variables file.

Karton session

Launcher, notifications, screenshots and session daemons that turn the compositor into a usable desktop flow.
